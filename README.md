A  collection of digital letters for someone special. Choose an envelope to open a heartfelt message for different moments, whether you're missing someone, having a bad day, or need a virtual hug.


features:

1)6 personalised letters to open for 6 different moods

2)interactive envelope selection

3)animated letter opening selection 

how to use:

1)Open the website.

2)Choose an envelope that matches how you're feeling.

3)Click the envelope to reveal your letter.

4) Read your message and return to the envelope page to open another.



languages used:HTML,CSS,JavaScript
